## Patterns
1. Sponsor bounty text is the rubric; format/eligibility failures lose (OpenClaw)
2. Arc escalating toward mainnet proof (≥50 tx; mainnet-gated payouts; 30% weight)
3. Saturation explicit: 97–98% agent projects; hidden gas / email onboarding / cross-chain are table stakes
4. **Recurring winning motif: payment conditional on quality/verification + refund** (Midstream, OpenBook, Chainlens, Mars, OpenPop)
5. Two-sided / real-world flows stand out (Gyasss, Onda, ETHastic)
6. Repeat winners ship infra others actually use (BlockRun)
7. Colosseum guidance: video < 3 min; show problem, target users, any user feedback; explain technical choices; solo builders say why they fit
8. Hackathon winners rarely have real traction; grant recipients almost always do

## Checklist (agent synthesis)
1. Map 30/25/25/20 to visible artifacts (Studio URL, addresses, tx hashes, video timestamps)
2. Mainnet USDC to counterparties you don't control (e.g., Circle marketplace x402 services); show 10–50+ distinct mainnet tx in a table
3. Show Studio-specific features on camera
4. Familiar workflow + one sharp mechanism twist stated in one line ("pay only if X verified, else auto-refund")
5. Name a specific user and pain, ideally your own, with numbers
6. Credible Circle Grant path (priority area, Circle products core, milestones)
7. Video < 3 min, architecture diagram, README evidence table
8. Submit early
