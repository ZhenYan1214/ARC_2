# Accrue

Milestone-based USDC grant escrow on [Arc](https://arc.io): funds waiting for a milestone earn yield in a Morpho ERC-4626 vault, are released the moment a milestone is approved, and auto-release if the reviewer does not respond in time.

Built for [Arc Microgrants: Built with Arc Studio](https://dorahacks.io/hackathon/arc-microgrants-2/detail).

## Status

Research and specification are done. Contracts and app are being built in Arc Studio.
